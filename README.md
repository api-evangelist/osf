OSF (Open Science Framework) is a free, open-source platform that supports the entire research lifecycle, enabling collaboration, data sharing, and reproducible workflows. Researchers can register projects, collect data, manage materials, and publish results, all while integrating with tools like Dropbox, GitHub, and more. The platform emphasizes openness, inclusivity, and long-term preservation of scholarly outputs.

**Areas:** Company · Open Science · Research · Collaboration · Platform · Open Source

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for OSF: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
